# Игра «Dasha and Sasha»

Короткая браузерная 2D-аркада для двоих за одной клавиатурой. 
Главные герои - Даша и Саша.

Игра работает офлайн, без установки, без библиотек и без сборки: чистый
JavaScript (ES-модули) + Canvas 2D. 
Ничего скачивать не нужно, кроме браузера с клавиатурой.

## Играть онлайн

Откройте: **https://romanpuzevich.github.io/dasha_sasha_game/**

Нужен компьютер с клавиатурой (телефон не подойдёт — управление только
с клавиатуры). Работает в Chrome, Safari и Firefox.

Если страница не открылась — запустите игру локально (инструкция ниже).

## Запустить локально

Нужен Python 3 — больше ничего.

```
git clone https://github.com/romanpuzevich/dasha_sasha_game.git
cd dasha_sasha_game
python3 serve.py
```

Затем откройте http://localhost:8000

`serve.py` — это обычный локальный сервер, но с отключённым кэшем. Просто
открыть `index.html` двойным кликом может не получиться: Chrome и Firefox
не загружают ES-модули с `file://`. А без запрета кэша Safari иногда
показывает старые сцены или `undefined` — если такое случилось, закройте
и откройте браузер полностью (или Cmd+Shift+R).

## Управление

Два игрока играют на одной клавиатуре.

| Действие | Даша (жёлтая) | Саша (красный) |
| --- | --- | --- |
| Движение | W A S D | ← ↑ → ↓ |
| Действие | Space | Enter |

На плашках «Нажмите Enter, чтобы продолжить» работает Enter. 
`F` — полноэкранный режим.
