# dasha_sasha_game

Свадебный подарок — 2D-игра (вид сверху) о жизни Даши и Саши. Чистый HTML5 + Canvas 2D: без библиотек, сборки и внешних файлов, все спрайты рисуются кодом.

## Как запустить

Двойной клик по `index.html` (на macOS: `open index.html`). Ничего устанавливать не нужно.

## Управление (два игрока за одной клавиатурой)

| Действие | Даша (жёлтая) | Саша (красный) |
| --- | --- | --- |
| Движение | W A S D | ← ↑ → ↓ |
| Действие 1 | Space | Enter |
| Действие 2 | E | Right Shift |

Раскладка универсальная и готова для всех уровней. В превью и на уровне 1 используется только «Действие 1» (удержание).

## Что уже есть

- **Превью:** дорога к зданию → коридор с четырьмя языковыми дверями → «Нажмите ENTER чтобы продолжить».
- **Уровень 1 «Кабинет английского»:** удерживайте кнопку — шпаргалка открыта, отпустите — спрятана. Если учитель застал со шпаргалкой, −10%; если успели спрятать, +2%. Заполните обе шкалы до 100% — уровень пройден.
