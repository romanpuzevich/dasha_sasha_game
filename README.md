# dasha_sasha_game

Свадебный подарок — 2D-игра (вид сверху) о жизни Даши и Саши. Чистый HTML5 + Canvas 2D, ES-модули: без библиотек и сборки.

## Как запустить

Двойной клик по `index.html` (на macOS: `open index.html`).

Если браузер не грузит ES-модули из `file://` (обычно это Chrome/Firefox), запустите локальный сервер и откройте http://localhost:8000:

```
python3 serve.py
```

`serve.py` — то же самое, что `python3 -m http.server`, но с запретом кэша.
Это важно: иначе после правок браузер (особенно Safari) может смешать новые
и старые JS-модули и показать «undefined» или старую сцену. Если уже видите
такое — один раз полностью закройте и откройте браузер (или жёсткая
перезагрузка Cmd+Shift+R), дальше используйте `serve.py`.

## Управление (два игрока за одной клавиатурой)

| Действие | Даша (жёлтая) | Саша (красный) |
| --- | --- | --- |
| Движение | W A S D | ← ↑ → ↓ |
| Действие | E или Space | Left Shift или Enter |

Обе клавиши действия игрока взаимозаменяемы. `F` — фулскрин. Раскладка готова для всех сцен.

## Что уже есть

Этапы 1–3 дорожной карты — **каркас, превью и Уровень 1**:

- мир 960×640, канвас на весь viewport с чёрными полями (letterbox);
- фиксированный игровой цикл 60 Гц, менеджер сцен с fade-переходом 0.3 с;
- стартовый экран: название игры (5 с), титры «МФТИ, 3 курс» (5 с); `Enter` — сразу в игру;
- превью 1 «МФТИ»: корпус микроэлектроники, отдельное здание КПМ слева, площадь со скамейками, памятник основателям с тремя фото-медальонами; светофор красный → жёлтый → зелёный, вся группа (герои + толпа) переходит дорогу с разных стартовых позиций, толпа обходит препятствия строго слева от памятника; у стеклянного входа широкая створка открывается, герои шагают вглубь тёмного проёма и скрываются у его середины, толпа идёт к двери параллельно и заходит по очереди;
- превью 2 «Коридор»: вертикальный коридор вдаль (тёмные стены по ~200 px по бокам, светлый пол в центре x = 200..760), четыре двери на стенах (x = 50 / x = 810, y = 150 / 350) с табличками над дверьми, подсказка «Выберите необходимую дверь», курсор-«мыш» дважды кликает «Английский» с зелёной подсветкой, плашка «Вы сделали правильный выбор!»;
- герои — фото-лица в кружке с рамкой цвета игрока (если файла нет — цветной круг);
- плашка «Нажмите Enter, чтобы продолжить», затем Уровень 1 «Кабинет английского»:
  Даша и Саша за партой (соседи «NPS» справа), учитель циклично «пишет» →
  «предупреждает» (красное «!») → «смотрит»; зажатая клавиша действия приподнимает
  шпаргалку из-под тетради, шкалы растут только при письме учителя; если он смотрит,
  а шпаргалка поднята — пойманы оба: −12 % шкалы, заморозка 0.5 с, вспышка и «бззз»;
  обе шкалы сомкнулись — «Уровень 1 пройден!» и переход к Уровню 2;
- Уровень 2 — заглушка «в разработке»: `Enter` возвращает на стартовый экран.

Отладка: `F2` — превью 1, `F3` — превью 2, `F4` — плашка, `F5` — Уровень 1.
