# AGENTS.md

## Проект

Личный свадебный подарок — 2D-игра (вид сверху) о жизни «Даши и Саши». Вся игра — один файл `index.html`: чистый HTML5 + Canvas 2D + JavaScript. Без сборки, зависимостей и внешних ассетов — все спрайты рисуются кодом.

Реализовано: превью (дорога к зданию, коридор с дверями) и уровень 1 («Кабинет английского»). Дальше — уровни 2–5.

## Как запустить

Открыть `index.html` двойным кликом в браузере (на macOS: `open index.html`). Установка и сервер не нужны.

## Проверка

Сборки и тестов нет. Быстрая проверка синтаксиса всего встроенного скрипта (нужен Node):

```
node -e 'const fs=require("fs");const m=fs.readFileSync("index.html","utf8").match(/<script>([\s\S]*)<\/script>/);new Function(m[1]);console.log("syntax ok")'
```

Если Node нет, подойдёт Deno — этим же способом запускается headless-симуляция полного прохождения (создаётся во временной папке, в репозиторий не коммитится).

## Правила для агентов

- Стек менять не надо и не добавлять зависимости, npm, сборщики, CI/релиз-обвязку и внешние ассеты без просьбы — это маленький приватный подарок.
- Вся игра — один `index.html` (CSS в `<style>`, JS в `<script>`); запуск двойным кликом.
- UI-текст и комментарии в игре — на русском, имена переменных/функций — на английском.
- Управление — через объект `INPUT` и `getPlayerInput(playerId)` (Даша: WASD + Space/E, Саша: стрелки + Enter/RightShift). Новые уровни делать на этой же раскладке.
- Игровой цикл — фиксированный шаг 60 FPS; функции на каждое состояние (`updatePreview1`, `drawLevel1` и т.д.); константы — вверху файла.
- Основная ветка — `main`; работа ведётся в ветках вида `feature/game-start`.
